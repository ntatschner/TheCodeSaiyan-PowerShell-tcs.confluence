## tcs.confluence Cmdlets
### [Add-ConfluenceAttachment](Add-ConfluenceAttachment.md)
Uploads files as attachments to a Confluence page.

### [Add-ConfluencePageLabel](Add-ConfluencePageLabel.md)
Adds labels to a Confluence page.

### [Clear-ConfluenceContext](Clear-ConfluenceContext.md)
Removes the Confluence site and credential stored by Set-ConfluenceContext.

### [ConvertTo-ConfluenceHTML](ConvertTo-ConfluenceHTML.md)
Converts simple Markdown to HTML for a Confluence page body.

### [Get-ConfluenceAttachment](Get-ConfluenceAttachment.md)
Gets the attachments of a Confluence page.

### [Get-ConfluenceContext](Get-ConfluenceContext.md)
Returns the Confluence connection set by Set-ConfluenceContext, without the credential.

### [Get-ConfluencePage](Get-ConfluencePage.md)
Gets Confluence pages by ID, by space or by title.

### [Get-ConfluencePageChild](Get-ConfluencePageChild.md)
Gets the child pages of a Confluence page, or with -Recurse all pages below it.

### [Get-ConfluencePageContent](Get-ConfluencePageContent.md)
Gets Confluence pages including their body in the requested format.

### [Get-ConfluencePageLabel](Get-ConfluencePageLabel.md)
Gets the labels of a Confluence page.

### [Get-ConfluenceSpace](Get-ConfluenceSpace.md)
Gets Confluence spaces, optionally filtered by name.

### [Invoke-ConfluenceRequest](Invoke-ConfluenceRequest.md)
Sends a request to the Confluence REST API using the current Confluence context.

### [Join-ConfluenceContent](Join-ConfluenceContent.md)
Joins blocks of Confluence content with a separator.

### [New-ConfluenceContentCodeBlock](New-ConfluenceContentCodeBlock.md)
Creates a Confluence code block macro.

### [New-ConfluenceContentDivider](New-ConfluenceContentDivider.md)
Creates a divider (horizontal rule or blank paragraph) for a Confluence page.

### [New-ConfluenceContentExpand](New-ConfluenceContentExpand.md)
Creates a Confluence expand macro (a collapsible section).

### [New-ConfluenceContentHeader](New-ConfluenceContentHeader.md)
Creates a heading (h1 to h6) for a Confluence page.

### [New-ConfluenceContentInfo](New-ConfluenceContentInfo.md)
Creates a Confluence info, tip, note or warning panel macro.

### [New-ConfluenceContentInternalLink](New-ConfluenceContentInternalLink.md)
Creates a link to a Confluence page, optionally to a heading on that page.

### [New-ConfluenceContentJiraIssue](New-ConfluenceContentJiraIssue.md)
Creates a Confluence Jira macro for one issue or a JQL query.

### [New-ConfluenceContentLink](New-ConfluenceContentLink.md)
Creates a hyperlink, or turns every URL in a block of text into a hyperlink.

### [New-ConfluenceContentStatus](New-ConfluenceContentStatus.md)
Creates a Confluence status lozenge (status macro).

### [New-ConfluenceContentTable](New-ConfluenceContentTable.md)
Creates an HTML table for a Confluence page from a collection of objects.

### [New-ConfluenceContentTOC](New-ConfluenceContentTOC.md)
Creates a Confluence table of contents macro.

### [New-ConfluencePage](New-ConfluencePage.md)
Creates a Confluence page, or with -Force updates the existing page with the same title.

### [New-ConfluencePageLayout](New-ConfluencePageLayout.md)
Creates a Confluence page layout with one or more sections of one to three columns.

### [Remove-ConfluencePage](Remove-ConfluencePage.md)
Deletes a Confluence page.

### [Remove-ConfluencePageLabel](Remove-ConfluencePageLabel.md)
Removes labels from a Confluence page.

### [Remove-DuplicateConfluencePage](Remove-DuplicateConfluencePage.md)
Removes duplicate Confluence pages that share a title and parent, keeping one.

### [Search-ConfluenceContent](Search-ConfluenceContent.md)
Searches Confluence with a CQL query.

### [Set-ConfluenceContext](Set-ConfluenceContext.md)
Sets the Confluence site and credential used by the other tcs.confluence commands.

### [Update-ConfluencePage](Update-ConfluencePage.md)
Replaces the title and body of a Confluence page.
